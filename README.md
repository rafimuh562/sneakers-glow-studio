## Deskripsi Proyek

Sneakers Glow Studio merupakan konsep layanan pencucian dan perawatan sepatu yang menyediakan tiga pilihan paket. Landing page ini memuat pengenalan layanan, katalog paket, serta kalkulator simulasi biaya berdasarkan paket, jumlah pasang sepatu, dan kode promo.

## Fitur

- Navigasi menuju Beranda, Katalog, dan Kalkulator.
- Hero section yang memperkenalkan layanan dan keunggulan bisnis.
- Katalog tiga paket perawatan sepatu beserta harga dan estimasi pengerjaan.
- Kalkulator harga berdasarkan pilihan paket dan jumlah pasang sepatu.
- Validasi kode promo `SEPATUKECE` untuk diskon 20%.
- Tampilan responsif untuk komputer, tablet, dan ponsel.

## Cara Menjalankan

1. Simpan keempat file di atas pada folder atau root repositori yang sama.
2. Buka `index.html` melalui peramban atau jalankan melalui OneCompiler HTML.
3. Uji kalkulator dengan memilih paket, mengisi jumlah pasang sepatu, dan memasukkan kode promo `SEPATUKECE`.
4. Unggah ke repositori GitHub publik.
5. Aktifkan GitHub Pages melalui **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
6. Ganti tautan GitHub Pages pada bagian Website di README ini dengan alamat yang diberikan GitHub.
